## 질문

기업이 필요한 파트너와 정보를 찾는 과정은 여러 채널에 흩어져 있었습니다. 우리는 이 탐색 과정을 어떻게 하나의 명확한 경험으로 만들 수 있을지 질문했습니다.

프로젝트의 핵심은 단순한 기업 목록이 아니었습니다. 사용자가 어떤 기준으로 회사를 비교하고, 어떤 정보가 연결 가능성을 판단하게 하며, 운영자는 어떤 방식으로 데이터를 보강해야 하는지를 함께 정리해야 했습니다.

## 해답

정보 구조를 다시 설계하고, 사용자가 목적에 따라 기업과 기회를 빠르게 비교할 수 있는 인터페이스를 만들었습니다. 운영자가 데이터를 지속적으로 확장할 수 있도록 관리 구조도 함께 정리했습니다.

## Pulda가 맡은 일

- 흩어진 요구를 플랫폼 정보 구조로 정리
- 기업 탐색과 비교에 필요한 화면 우선순위 설계
- 운영자가 데이터를 축적할 수 있는 관리 흐름 검토
- 서비스 확장을 고려한 기본 웹 구조 구현

이 프로젝트는 Pulda가 단순한 홍보 페이지뿐 아니라, 데이터와 운영 흐름이 있는 웹 서비스를 어떻게 기획하고 화면으로 정리하는지 보여주는 사례입니다.

## 결과

복잡했던 기업 탐색과 연결 과정이 하나의 플랫폼 안에서 이어지며, 데이터가 쌓일수록 더 유용해지는 서비스 기반을 마련했습니다.

아직 공개 케이스 스터디로 더 많은 화면 자료를 보강해야 하지만, 현재 사이트에서는 Pulda의 B2B 플랫폼 기획과 정보 구조 설계 역량을 보여주는 기본 사례로 활용합니다.
