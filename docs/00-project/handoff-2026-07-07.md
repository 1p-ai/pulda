## 5. Do Not Repeat

- **코드 전체 덮어쓰기 금지**: `dev.md` 원칙에 따라, 기존 코드를 읽고 필요한 부분만 작게 수정한다. 특히 AI 어시스턴트가 파일을 통째로 재생성하지 않도록 주의한다.
- **사이드이펙트 간과 금지**: CSS 수정 시, 라이트/다크 모드 양쪽에 미치는 영향을 항상 확인한다.
- **빌드 통과와 시각적 확인 혼동 금지**: `npm run build` 성공이 곧바로 브라우저에서의 완벽한 렌더링을 의미하지 않는다. 주요 변경 후에는 반드시 시각적 QA를 병행한다.
- **기준 원본 혼동 금지**: 소스 기준은 항상 GitHub 저장소의 `site/src/`와 `site/public/`이다. `site/dist/`나 `code.html` 시안 파일을 수정하지 않는다.
- **지식 원본 혼동 금지**: Notion은 '지식 기록'의 원본이며, GitHub는 '실시간 소스'의 원본이다. 역할을 명확히 구분한다.
