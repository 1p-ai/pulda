## 1. 디자인 원칙

Pulda의 디자인은 전통 상징을 장식으로 쓰지 않고 문제 해결의 태도로 번역한다. 라이트 모드는 사람, 전통, 여백, 연결을 보여주고, 다크 모드는 기술, 시스템, 인더스트리얼 감각을 보여준다.

## 3. 타이포그래피

- 라이트의 주요 한글 제목은 Solmoe Kim Daegeon 계열을 사용한다.
- 본문과 정보 구조는 Hanken Grotesk, Noto Sans KR 계열을 사용한다.
- 다크 모드에서는 붓글씨보다 견고한 고딕/그로테스크 계열을 우선한다.
- 모바일에서는 제목 겹침을 피하고 줄바꿈과 폭 제어를 우선한다.

## 4. 레이아웃

- 12컬럼 기반의 큰 여백을 유지한다.
- 섹션은 과도한 카드 중첩보다 명확한 정보 흐름을 우선한다.
- 프로젝트는 넓고 전시적인 케이스 스터디 감각을 가진다.
- 스토리는 좁고 읽기 중심의 저널 감각을 가진다.

## 5. 컴포넌트 기준

### 버튼

- Primary: 딥블루 배경과 밝은 종이색 텍스트
- Hover: 오래된 홍색 또는 테크 레드로 강조
- 다크 모드: 네온 레드와 글로우를 제한적으로 사용

### 태그/라벨

- 라이트: Old Taegeuk Red의 선과 텍스트
- 다크: Tech Red의 선과 약한 광원
- 태그는 초기에는 정보 보조용이며 필터 UI는 나중에 노출한다.

### 메뉴

- 라이트 모바일: 부채꼴 메뉴 자산 사용
- 다크 모바일: 일반 햄버거/X 메뉴 사용

## 6. 테마별 표현

| 영역 | 라이트 | 다크 |
| --- | --- | --- |
| 로고 | 한글 붓글씨 로고 | PULDA 워드마크 |
| 언어 | 한글 중심 | 영문 중심 |
| 배경 | 한지/빛바랜 천 | 테크 네이비/그리드 |
| 강조 | 오래된 홍색 | 네온 레드 |
| 모션 | 명주실이 풀리는 흐름 | 광원이 뿜어지는 흐름 |

## 7. 금지/주의

- 라이트 모드 신규 UI에 순백색과 차가운 회백색을 쓰지 않는다.
- 전통 요소를 장식으로만 소비하지 않는다.
- 다크 모드가 게임 UI처럼 과도하게 보이지 않도록 네온 사용량을 제한한다.
- `site/dist/`를 디자인 기준 소스로 삼지 않는다.
