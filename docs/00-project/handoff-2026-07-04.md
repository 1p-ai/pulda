구현된 주요 범위:

- 홈, 소개, 프로젝트, 스토리, 문의, 운영 포털 /admin
- 라이트/다크 테마 전환과 초기 깜빡임 방지
- 메인 파트너/클라이언트 신뢰 신호 영역
- 라이트 모드 부채 메뉴 애니메이션과 효과음
- 다크 모드 메뉴 효과음
- 프로젝트 샘플: A4U, Pulda 공식 웹사이트 리뉴얼, 은조 아임웹 홈페이지
- 스토리 샘플: why-we-are-pulda, clarity-before-decoration
- /admin은 실제 CMS가 아니라 Sanity/통계/배포 체크리스트로 가는 운영 포털
- QA 자동검증 site/scripts/qa-check.mjs
- 역할형 MD 체계: agent.md, pm.md, qa.md, PL-01~PL-06

최근 검증:

- npm run build 통과
- qa-check 통과
- 브라우저에서 /project/, /story/, /project/pulda-official-website-renewal/, /story/why-we-are-pulda/ 정상 접근 확인

## 6. Do Not Repeat

- 라이트 모드 지시를 공통 CSS에 적용해 다크 모드에 사이드이펙트를 만들지 않는다.
- 다크 모드는 붓글씨/전통 자산이 아니라 직선, 네온, 시스템 문법을 유지한다.
- PM이 모든 구현을 직접 떠안지 않는다. 실제 코드 수정은 PL-06 Development 관점으로 검토한다.
- 빌드 통과와 브라우저 접근 확인을 같은 것으로 보지 않는다.
- /admin noindex를 접근 제어로 착각하지 않는다.
- 실제 로고 이미지가 없는 상태에서 파트너 로고를 확정 자산처럼 표현하지 않는다.
- site/dist는 빌드 산출물이며 원칙적으로 직접 수정하지 않는다.
