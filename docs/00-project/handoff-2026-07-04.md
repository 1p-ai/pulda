## 1. Current State

Pulda 공식 웹사이트는 `site/` 폴더의 Astro 정적 사이트가 실제 기준 프로젝트다. 기준 소스는 `site/src/`와 `site/public/`이며, `site/dist/`는 빌드 산출물이다.

구현된 주요 범위:

- 홈, 소개, 프로젝트, 스토리, 문의, 운영 포털 `/admin`
- 라이트/다크 테마 전환과 초기 깜빡임 방지
- 메인 파트너/클라이언트 신뢰 신호 영역

- 다크 모드 메뉴 효과음과 직선 네온 hover
- 프로젝트 샘플: A4U, Pulda 공식 웹사이트 리뉴얼, 은조 아임웹 홈페이지
- 스토리 샘플: why-we-are-pulda, clarity-before-decoration
- `/admin`은 실제 CMS가 아니라 Sanity/통계/배포 체크리스트로 가는 운영 포털
- QA 자동검증 `site/scripts/qa-check.mjs`
- GitHub Desktop 기준 저장소 연결과 루트 `.gitignore` 생성

최근 운영 결정:

- GitHub는 실시간 소스와 MD 기준 원본이다.
- Notion은 지식 기록의 원본이자 프로젝트 사관이다.

- `dev.md`를 생성해 코드 전체 재생성 방지, 기존 구현 보존, 히스토리 주석 원칙을 추가했다.

## 4. Latest Strategic Notes

### Source and Knowledge

- GitHub: 실시간 소스와 MD 기준 원본
- Notion: 지식 기록의 원본, 프로젝트 다이어리, 사관
- Google Drive: 대용량 참고 파일과 원본 자료 보관
- NotebookLM: 프로젝트별 압축 요약과 작업 기준 백업
- ChatGPT: 기획 초안과 질문 정리
- Codex/Replit: GitHub 기준 원본을 받아 수행
- Stitch 2.0: 시안 컨셉과 HTML 초안

### Local Autonomy

- 현재는 ChatGPT/Codex 중심으로 빠르게 처리한다.
- 맥미니 도입 이후 Hermes Agent와 빠른 로컬 에이전트를 배치해 반복 업무, 파일 정리, 초벌 QA, 문서 요약을 맡긴다.
- 클라우드 AI와 외부 서비스는 부모, 로컬 AI와 로컬 에이전트는 성장시킬 자녀라는 가족 모델로 이해한다.
- 현재는 자유무역/외부의존형 성장기이고, 장기적으로 독립과 자립의 영역을 구축한다.

### Technology Sovereignty

- AI 노트북, 소버린 AI 같은 용어는 마케팅 문구와 실제 기능을 분리해 이해한다.
- 흐름에는 올라타되, 위기에 대비한다.
- 기술 주권은 완전한 고립이 아니라 위기 때 최소 업무를 유지할 수 있는 선택권이다.

### Education and Game Concept

- AI 시대에는 빨리 많이 아는 것보다 정확히 아는 것이 중요하다.
- 기초 인문학, 기초 과학, 예체능 경험, 사유 경험을 장기 역량의 기반으로 본다.
- `슬라임맨과 비겁한 용사`는 Pac-Man식 평면 미로, Lode Runner식 중력/층 구조, 모바일 햅틱 미로를 결합한 장기 이스터에그/교육용 에디터 후보다.
- 공개 후보 시점은 아이 생일인 5월 12일 전후 또는 회사 설립일인 6월 1일이다.

## 7. Do Not Repeat

- 라이트 모드 지시를 공통 CSS에 적용해 다크 모드에 사이드이펙트를 만들지 않는다.
- 다크 모드는 붓글씨/전통 자산이 아니라 직선, 네온, 시스템 문법을 유지한다.
- 기존 코드를 통째로 새로 생성하거나 덮어쓰지 않는다. `dev.md` 기준으로 작은 패치와 히스토리 주석을 우선한다.
- PM이 모든 구현을 직접 떠안지 않는다. 실제 코드 수정은 PL-06 Development 관점으로 검토한다.
- 빌드 통과와 브라우저 접근 확인을 같은 것으로 보지 않는다.
- `/admin` noindex를 접근 제어로 착각하지 않는다.
- `site/dist/`는 빌드 산출물이며 원칙적으로 직접 수정하지 않는다.
- Notion은 소스 원본이 아니라 지식 기록 원본이다. 소스 기준은 GitHub다.
- Stitch/Replit 실험 결과는 초안이며, 실제 반영은 `site/src/`와 `site/public/`에 옮겨 검증한다.
