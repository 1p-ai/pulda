## 2. 홈 화면

### 2.1 히어로

- 목표: Pulda의 첫 인상을 결정한다.
- 주요 문구: 라이트는 “어려움은 풀고, 올바름을 향합니다.”, 다크는 “Engineered Clarity.”
- 시각 요소: 라이트는 한지와 실 흐름, 다크는 테크 네이비와 네온 흐름
- CTA: 프로젝트 보기, 서비스 영역 이동

### 2.2 소개 요약

- 목표: Pulda가 문제를 다루는 방식을 짧게 설명한다.
- 구성: 철학 라벨, 대형 제목, 설명 문단, 지표

### 2.3 서비스

- 목표: 전략, UI/UX, 개발 역량을 정리한다.
- 구성: 번호, 서비스명, 설명, 화살표

### 2.4 프로젝트 프리뷰

- 목표: 작업 사례로 신뢰를 만든다.
- 구성: 대표 카드 2개, 프로젝트명, 설명

### 2.5 문의 CTA

- 목표: 문의 행동으로 이어지게 한다.
- 구성: 질문 문구, 이메일 링크

## 3. 소개 페이지

- 목표: Pulda의 기준과 태도를 설명한다.
- 구성: 페이지 헤드, 기준 섹션, 태도 섹션, 프로젝트 CTA
- 비고: 메인과 중복되는 거대한 소개보다 문장 정밀도를 우선한다.

## 4. 프로젝트 목록

- 목표: 작업 사례를 케이스 스터디 전시장처럼 보여준다.
- 구성: 날짜, 클라이언트/서비스, 제목, 설명, 결과 요약, 태그, 주요 서비스, 상세 이동
- 인터랙션: 항목 hover, 상세 이동

## 5. 프로젝트 상세

- 목표: 기획 의도, 과정, 산출물, 결과를 설명한다.
- 구성: 헤드, client/scope/outcome 메타 패널, 본문, 목록 복귀
- 비고: 향후 이미지, 링크, 산출물 갤러리 확장 가능

## 6. 스토리 목록

- 목표: 기업 블로그 피드를 제공한다.
- 구성: 카테고리/작성자, 제목, 설명, 날짜, 상세 이동
- 비고: 초기에는 카테고리 탭 없이 단일 피드

## 7. 스토리 상세

- 목표: 글 읽기에 집중한다.
- 구성: 헤드, 메타, 좁은 본문, 목록 복귀

## 8. 문의 페이지

- 목표: 연락 행동을 만든다.
- 구성: 문의 메시지, 이메일, 협업 안내 문구
- 향후: 문의 폼 또는 CRM 연동 가능
