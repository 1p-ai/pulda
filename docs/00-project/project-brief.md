# 프로젝트 개요서

- 문서 상태: Draft
- 기준일: 2026-07-03

## 프로젝트명

Pulda 웹사이트 구축 프로젝트

## 프로젝트 목적

Pulda의 브랜드 철학, 서비스 역량, 프로젝트 사례, 기업 블로그형 콘텐츠를 하나의 웹 경험으로 정리한다. 사이트는 단순 회사 소개를 넘어 “복잡함을 풀어 명확한 디지털 경험으로 만든다”는 Pulda의 문제 해결 태도를 보여주는 브랜드/영업/콘텐츠 허브 역할을 한다.

## 핵심 목표

- Pulda의 정체성을 라이트/다크 두 얼굴로 표현한다.
- 소개, 프로젝트, 스토리, 문의 페이지를 실제 경로 기반으로 제공한다.
- 프로젝트는 케이스 스터디 전시장으로, 스토리는 기업 블로그로 운영한다.
- 정적 사이트의 빠른 응답성과 SEO 기본 요건을 확보한다.
- 향후 Sanity CMS 연결을 고려한 콘텐츠 모델을 유지한다.

## 현재 범위

포함:

- Astro 기반 정적 웹사이트
- 메인 페이지
- 소개 페이지
- 프로젝트 목록/상세
- 스토리 목록/상세
- 문의 페이지
- RSS, sitemap, robots
- 라이트/다크 테마
- Markdown 기반 초기 콘텐츠

제외 또는 보류:

- Sanity Studio 실제 구축 및 외부 배포 연결
- 회원/로그인 기능
- 관리자 권한 관리
- 검색, 태그 필터, 카테고리 탭의 화면 노출
- 최종 완료보고서와 운영 인수인계서

## 주요 의사결정

- 실제 웹사이트 기준은 `site/` 폴더의 Astro 프로젝트다.
- 라이트와 다크는 별도 HTML이 아니라 단일 페이지의 테마 분기로 관리한다.
- 라이트는 한지, 오래된 홍색, 깊은 태극 청색, 붓글씨 정서를 사용한다.
- 다크는 테크 네이비, 네온 레드, 영문 워드마크, 시스템형 UI를 사용한다.
- 콘텐츠는 초기에는 Markdown으로 관리하고, Sanity 연결 시 같은 필드를 이전한다.

## 성공 기준

- 주요 경로가 모두 200으로 응답한다.
- 다크 모드 페이지 이동 시 라이트 화면이 먼저 노출되지 않는다.
- 프로젝트/스토리의 화면 성격이 구분된다.
- 콘텐츠 추가 시 URL, 메타데이터, sitemap, RSS가 자동 반영된다.
- 프로젝트 운영 기준과 디자인 의사결정이 문서로 추적된다.
